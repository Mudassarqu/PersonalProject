How to publish on GitHub Pages & link from Google Sites

Upload all 6 files to GitHub. Create a new repository (e.g. myp-pp-samples). Upload all 6 HTML files — rename pp_index.html to index.html — keeping them all in the root folder together.
Enable GitHub Pages. Go to your repo → Settings → Pages. Under Source, choose Deploy from a branch, select main branch and / (root) folder. Click Save. After a minute your site is live at https://yourusername.github.io/myp-pp-samples/
Test navigation locally. Open index.html in a browser — clicking any card opens that report, and the dark bar at the top of each report takes you back to the index. All links are relative so they work both locally and on GitHub Pages.
Link from Google Sites. In Google Sites, add a Button or Text link pointing to your GitHub Pages URL. Alternatively use Insert → Embed → By URL to show the index page inline (note: some Google Sites configurations block external embeds — a direct link works reliably for all users).
